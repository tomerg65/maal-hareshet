# מעל הרשת ע״י אלי

אתר עדכונים לליגת העל בכדורעף, גברים ונשים: תוצאות, טבלה, לוח משחקים, קבוצות וסגלים, חדשות ורכש.

- `build.py` מושך את הנתונים מאתר איגוד הכדורעף ואת כותרות החדשות, ובונה את `docs/`.
- `template.html` הוא הדף עצמו.
- `.github/workflows/update.yml` מריץ את הבנייה כל 10 דקות ומפרסם ל-GitHub Pages.
